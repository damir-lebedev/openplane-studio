# OpenPlane Studio

Приложение для самолёта на прошивке [OpenPlane](https://github.com/damir-lebedev/OpenPlaneProject):
настроить плату по шагам, собрать прошивку под свой самолёт и прошить её одной
кнопкой. Остальные разделы — полёты, онлайн, чёрный ящик и грузы — пока
заглушки «Скоро». План и список дел — [PLAN.md](PLAN.md).

Сделано: **Tauri 2** (внутри Rust) + React + TypeScript. Работает без интернета.

## Что умеет сейчас

- **Ангар.** Самолёт — папка в `Документы/OpenPlane/Hangar/<id>/`:
  `plane.json` и `history/` (снимок конфигурации на каждую прошивку). Новый
  самолёт можно взять из прошивки как есть (твои `Config.h`, `Controls.h`,
  `SensorSelection.h`) или начать с нуля.
- **Мастер по шагам.** Плата → самолёт → датчики → (пульт) → тумблеры →
  (безопасность, система) → проверка. Шаги открываются по порядку: тумблеры —
  только после датчиков. Простой режим — главное, полный — каждый параметр
  прошивки и таблица «Все параметры» с поиском.
- **Что чему нужно.** Режим без нужного датчика серый: «Для работы режима RTH
  нужны датчики: GPS» и кнопка «Добавить». Убрал датчик — всё, что от него
  зависело, краснеет, «Прошить» заблокирована. Правила — из меток `@needs` в
  прошивке, а не из приложения.
- **Пульт на экране.** FS-i6: на какое положение какого тумблера какой режим,
  функция или крутилка. SwA (ARM) и стики под замком, как в прошивке.
- **Прошивка одной кнопкой.** Конфигурация записывается в копию исходников
  (`tools/opconfig.py apply`), собирается PlatformIO, плата сама уходит в
  загрузчик (клавиша `D` прошивки), заливка — dfu-util или esptool, в конце
  плата отвечает паспортом (`@id`) — приложение сверяет хэш конфигурации.
  Ошибки — по-русски и с действием: «порт занят монитором — закрыть?»,
  «включите режим прошивки: BT0 на 3V3 и RST», «нет драйвера DFU».

Ещё не сделано (по [PLAN.md](PLAN.md)): установка драйвера DFU в один клик
(пока — подсказка про Zadig), установка PlatformIO из приложения, 3D-модель,
живой пульт и мастер наладки после прошивки, этап 2 — параметры в памяти
платы без компиляции.

## Как запустить

Нужно один раз: [Node.js](https://nodejs.org) 22+, [Rust](https://rustup.rs) и
Visual Studio Build Tools (C++), [PlatformIO](https://platformio.org) и
исходники прошивки OpenPlane (папка `plane` рядом или «Взять с GitHub» в
настройках).

```bash
npm install
npm run app        # окно приложения в режиме разработки
npm test           # тесты правил и конфигурации (vitest)
npm run tauri build   # установщик Windows (NSIS) в src-tauri/target/release/bundle
```

Описание прошивки для тестов (`src/core/__fixtures__/manifest.json`)
обновляется из исходников прошивки:

```bash
python ../plane/tools/opconfig.py describe --root ../plane --out src/core/__fixtures__/manifest.json
```

## Как устроено

| Где | Что |
|---|---|
| `src/core/` | без интерфейса: описание прошивки, самолёт, правила «что чему нужно», конфигурация для прошивки — с тестами |
| `src/components/` | интерфейс: каркас, ангар, мастер, пульт, таблица параметров, окно прошивки |
| `src/flash.ts` | кнопка «Прошить»: сборка → плата в загрузчик → заливка → проверка паспорта |
| `src-tauri/src/` | Rust: USB и COM-порты, PlatformIO, файлы ангара, монитор порта |
| прошивка `tools/opconfig.py` | описание прошивки и запись конфигурации — живёт в репозитории прошивки, чтобы не разъезжаться с ней |
